

## 🎉 Fest Website

A responsive and interactive **Fest Website** developed using **HTML, CSS, and JavaScript**.
This website is designed to showcase fest details such as events, schedule, gallery, and contact information in a user-friendly way.

---

## 🚀 Features

* 🎨 Attractive and responsive UI
* 📱 Mobile-friendly design
* 🗓️ Fest events & schedule section
* 🖼️ Image gallery
* 📍 Contact / Registration section
* ⚡ Smooth animations and interactions using JavaScript

---

## 🛠️ Technologies Used

* **HTML5** – Structure of the website
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and dynamic behavior
